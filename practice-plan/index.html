📓 An Eight-Minute Krillion Practice Plan

A useful practice session gives the next dive one small change to try. This plan works with pencil and paper or the sample prompts in this guide.

📆 Divide eight minutes into four jobs

Pick four practice questions that share one difficulty, such as a category that adds a location. Give each question 25 seconds. Use the rest of the three-minute answering block to mark the one word or decision that slowed you down.

🐟 Picture two levels of the same practice

📓 Log the decision instead of the score

Write one line per recurring issue. You can use the same notes with the sample prompt set or a replay.

What you noticedOne-line noteWhat to try next
Slow first thoughtI looked at the word “sport” and thought only of teams.Name one individual sport first on the next card.
Ambiguous candidateI knew a river basin but guessed a country.Say the expected kind of answer before typing.
Long typing delayI chose a long title with two uncertain words.Keep a short candidate ready.

🔁 Test one change at the end

Use the last two minutes for a new prompt with the same difficulty. If the note said “I jumped to a coast before reading the sea name,” speak the sea name first on the new card. See whether that brings a clear candidate to mind faster. A good test shows whether the move transfers to a fresh category.

After the next scored dive, use the recap to check one round that used that skill. If you only have a short window before playing, use the quick warm-up.
